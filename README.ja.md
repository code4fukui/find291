# find291

福井県の美しさを発見し、共有するためのフォトアーカイブプロジェクトです。

## デモ

[https://find291.jp/](https://find291.jp/)

## 特徴

- **クラウドソース写真**: 福井県の自然の風景や観光地の写真を投稿できます。
- **アーカイブの探索**: 投稿された写真を閲覧・共有し、福井県の隠れた魅力を発見できます。
- **アイデアの共有**: 投稿に撮影場所や撮影のアイデアを含めることができます。
- **バイリンガル対応のドキュメント**: READMEは日本語と英語で用意されています。ウェブサイトは現在日本語のみです。

## はじめに

本プロジェクトはHTMLとCSSで構築された静的ウェブサイトであり、GitHub Pagesでホストされています。インストールは不要です。

ローカル環境でサイトを実行するには：
1. リポジトリをクローンします。
2. ウェブブラウザで `index.html` を開きます。

## 謝辞

このプロジェクトは、日本の47都道府県を対象としたフォトアーカイブである [FIND/47](https://find47.jp/) のフォークです。

ビジュアルデザインとCSSはオリジナルプロジェクトに基づいており、[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) ライセンスの下で提供されています。
- `style.css`: `from https://find47.jp/assets/styles/style.css`
- `index.html`: `forked from https://find47.jp/`
