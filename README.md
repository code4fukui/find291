# find291

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A photo archive project to discover and share the beauty of Fukui, Japan.

## Demo

[https://find291.jp/](https://find291.jp/)

## Features

-   **Crowdsourced Photos**: Submit photos of Fukui's natural scenery and attractions.
-   **Explore the Archive**: Browse and share submitted photos to discover Fukui's hidden gems.
-   **Share Ideas**: Include photo locations and shooting ideas with submissions.
-   **Bilingual Documentation**: READMEs are available in Japanese and English. The website is currently in Japanese.

## Getting Started

This is a static website built with HTML and CSS, hosted on GitHub Pages. No installation is required.

To run the site locally:
1.  Clone the repository.
2.  Open `index.html` in your web browser.
